# Course data

All files in this folder are **simulated** by `simulate_data.py` (fixed random seed). They imitate real agricultural and biological data — including missing values, outliers, site effects, population structure, batch effects and contaminants — so that the labs can teach how to detect them. Genus names are labels only; the DNA sequences are synthetic, not real 16S rRNA genes.

Regenerate with:

```bash
python data/simulate_data.py
```

A full description of every file is on the website's [Datasets](../resources/datasets.qmd) page.
